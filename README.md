# Git & GitHub Practice Lab

## Summary

This repository contains the work completed for the Git & GitHub Practice laboratory exercise. The purpose of this lab was to
gain practical experience with Git and GitHub by creating a remote repository, cloning it to a local machine, modifying project
files,tracking changes, creating commits, and synchronizing updates with GitHub. Through this exercise, I learned the basic Git 
workflow and how version control is used to manage software projects efficiently.

## Overview

This repository demonstrates the fundamental operations of Git version control. The lab involved creating a GitHub repository,
adding a C++ source file (main.cpp), updating the file with personal information, committing the changes, and pushing  the
updated version to the remote repository.

## Objectives

- Understand the fundamentals of Git and GitHub.
- Create and manage a GitHub repository.
- Clone a remote repository to a local machine.
- Track file modifications using Git.
- Stage and commit changes with meaningful commit messages.
- Push local commits to a remote GitHub repository.
- Gain hands-on experience with the standard Git workflow.

## Tasks Performed

- Created a public GitHub repository.
- Added the initial main.cpp file.
- Cloned the repository to the local computer.
- Verified the repository status.
- Updated the program with personal information.
- Viewed file changes using Git.
- Staged the modified file.
- Created a commit with a descriptive message.
- Pushed the updated repository to GitHub.

## Learning Outcomes

After completing this laboratory exercise, I was able to:

- Configure and use Git for version control.
- Clone and manage remote GitHub repositories.
- Track, stage, and commit changes to project files.
- Synchronize local and remote repositories using GitHub.
- Understand the complete Git workflow used in collaborative software development.
